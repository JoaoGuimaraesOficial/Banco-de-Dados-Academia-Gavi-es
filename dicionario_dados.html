2. Visão geral do banco de dados

O banco atende uma unidade da academia que funciona 24 horas, em quatro turnos (madrugada, manhã, tarde e noite). Ele guarda os dados de alunos, planos, matrículas e pagamentos, treinos, aulas coletivas com check-in, comunicação entre turnos, chamados de manutenção e estoque de materiais. São 13 entidades.

Convenção Definição
SGBD MySQL 8 (InnoDB)
Codificação utf8mb4, com collation utf8mb4_0900_ai_ci
Prefixos ID_ identificador, NM_ nome, DT_ data, CD_ código, QT_ quantidade, TP_ tipo/categoria, IN_ indicador booleano, DS_ descrição/texto livre, VL_ valor monetário
Notação da composição @ identificador, + elementos obrigatórios, ( ) opcional

4. Dicionário detalhado das entidades

ALUNO

Cliente que contrata a academia; é a base para acesso, cobrança e treinos.

Composição: = @ID_ALUNO + NM_ALUNO + ID_CPF + NM_EMAIL + DT_NASCIMENTO + (DS_FOTO_PERFIL) + (DS_BIOMETRIA_FACIAL) + IN_ATIVO

Atributo Tipo Obrigatório Observação
ID_ALUNO int Sim (PK) Identificador interno
NM_ALUNO varchar(120) Sim Nome completo
ID_CPF varchar(11) Sim (único) Usado na busca pela recepção
NM_EMAIL varchar(100) Sim E-mail de contato; também serve para buscar o aluno na recepção
DT_NASCIMENTO date Sim Data de nascimento do aluno
DS_FOTO_PERFIL varchar(255) Não Foto de perfil; pode ser cadastrada depois
DS_BIOMETRIA_FACIAL text Não Cadastro facial usado na catraca; vale em outras unidades
IN_ATIVO tinyint(1) Sim Cadastro ativo; muda com inadimplência prolongada

Índices: PK em ID_ALUNO; índices secundários em ID_CPF e NM_ALUNO.

PLANO

Plano comercial que o aluno pode contratar, separado do cadastro do aluno.

Composição: = @ID_PLANO + NM_PLANO + TP_RECORRENCIA + VL_MENSALIDADE + IN_ATIVO

Atributo Tipo Obrigatório Observação
ID_PLANO int Sim (PK) Identificador do plano
NM_PLANO varchar(60) Sim Nome do plano
TP_RECORRENCIA varchar(20) Sim Tipo de cobrança: recorrente (automática no cartão) ou não recorrente (avulsa)
VL_MENSALIDADE decimal(10,2) Sim Valor da mensalidade (maior que 0)
IN_ATIVO tinyint(1) Sim Plano disponível para novas adesões

MATRICULA (entidade associativa entre ALUNO e PLANO)

Liga o aluno a um plano e guarda o período do contrato.

Composição: = @ID_MATRICULA + ID_ALUNO + ID_PLANO + DT_INICIO + (DT_FIM) + TP_STATUS + (CD_ULTIMOS_DIGITOS_CARTAO)

Atributo Tipo Obrigatório Observação
ID_MATRICULA int Sim (PK) Identificador da matrícula
ID_ALUNO int Sim (FK) Referencia ALUNO
ID_PLANO int Sim (FK) Referencia PLANO
DT_INICIO date Sim Data de início do contrato
DT_FIM date Não Preenchida no cancelamento
TP_STATUS varchar(20) Sim Situação da matrícula: pago, pendente, inadimplente ou cancelado; inadimplente bloqueia a catraca
CD_ULTIMOS_DIGITOS_CARTAO varchar(4) Não Só os 4 últimos dígitos do cartão, sem expor o número completo

PAGAMENTO

Pagamentos feitos em cada matrícula.

Composição: = @ID_PAGAMENTO + ID_MATRICULA + DT_PAGAMENTO + VL_PAGAMENTO + TP_FORMA_PAGAMENTO + TP_STATUS

Atributo Tipo Obrigatório Observação
ID_PAGAMENTO int Sim (PK) Identificador do pagamento
ID_MATRICULA int Sim (FK) Referencia MATRICULA
DT_PAGAMENTO date Sim Data do pagamento
VL_PAGAMENTO decimal(10,2) Sim Valor pago (maior que 0)
TP_FORMA_PAGAMENTO varchar(20) Sim Forma de pagamento: PIX, dinheiro, cartão de crédito ou cartão de débito
TP_STATUS varchar(20) Sim Situação do pagamento, como realizado ou cartão recusado

FUNCIONARIO

Quem trabalha na academia: recepção, professores, gerente e financeiro.

Composição: = @ID_FUNCIONARIO + NM_FUNCIONARIO + ID_CPF + TP_PAPEL + IN_ATIVO

Atributo Tipo Obrigatório Observação
ID_FUNCIONARIO int Sim (PK) Identificador do funcionário
NM_FUNCIONARIO varchar(120) Sim Nome completo
ID_CPF varchar(11) Sim (único) CPF do funcionário
TP_PAPEL varchar(20) Sim Função na academia: recepção, professor, gerente ou financeiro; define as permissões de acesso
IN_ATIVO tinyint(1) Sim Funcionário em atividade

TREINO

Ficha de treino de um aluno, montada por um professor.

Composição: = @ID_TREINO + ID_ALUNO + ID_PROFESSOR + DT_CRIACAO + DT_VALIDADE + (DS_OBSERVACAO_MEDICA)

Atributo Tipo Obrigatório Observação
ID_TREINO int Sim (PK) Identificador da ficha de treino
ID_ALUNO int Sim (FK) Referencia ALUNO
ID_PROFESSOR int Sim (FK) Referencia FUNCIONARIO (professor que montou o treino)
DT_CRIACAO date Sim Data em que a ficha foi criada
DT_VALIDADE date Sim Data limite da ficha; depois dela o treino precisa ser renovado
DS_OBSERVACAO_MEDICA text Não Limitações físicas do aluno

AULA_COLETIVA

Aulas em grupo, com horário, instrutor, unidade e limite de vagas.

Composição: = @ID_AULA + ID_INSTRUTOR + ID_UNIDADE + NM_MODALIDADE + DT_HORARIO + QT_LIMITE_VAGAS

Atributo Tipo Obrigatório Observação
ID_AULA int Sim (PK) Identificador da aula
ID_INSTRUTOR int Sim (FK) Referencia FUNCIONARIO (instrutor da aula)
ID_UNIDADE int Sim (FK) Referencia UNIDADE
NM_MODALIDADE varchar(60) Sim Spinning, boxe, muay thai etc.
DT_HORARIO datetime Sim Data e horário da aula
QT_LIMITE_VAGAS int Sim 19 para o spinning

CHECKIN_AULA (entidade associativa entre ALUNO e AULA_COLETIVA)

Reserva do aluno em uma aula coletiva.

Composição: = @ID_CHECKIN + ID_AULA + ID_ALUNO + DT_REALIZACAO

Atributo Tipo Obrigatório Observação
ID_CHECKIN int Sim (PK) Identificador do check-in
ID_AULA int Sim (FK) Referencia AULA_COLETIVA
ID_ALUNO int Sim (FK) Referencia ALUNO
DT_REALIZACAO datetime Sim Data e hora do check-in

Índices: Índice único composto em (ID_AULA, ID_ALUNO), que evita reserva duplicada.

OCORRENCIA_TURNO

Recados e pendências que um turno deixa para o próximo.

Composição: = @ID_OCORRENCIA + ID_FUNCIONARIO_AUTOR + DT_REGISTRO + TP_TURNO + DS_MENSAGEM + IN_RESOLVIDO

Atributo Tipo Obrigatório Observação
ID_OCORRENCIA int Sim (PK) Identificador da ocorrência
ID_FUNCIONARIO_AUTOR int Sim (FK) Referencia FUNCIONARIO (quem registrou)
DT_REGISTRO datetime Sim Data e hora do registro
TP_TURNO varchar(20) Sim Turno: madrugada, manhã, tarde ou noite
DS_MENSAGEM text Sim Pendência ou aviso para a equipe do próximo turno
IN_RESOLVIDO tinyint(1) Sim Começa como não resolvida

ITEM_TREINO (itens e exercícios da ficha de treino)

Exercícios que fazem parte de uma ficha de treino.

Composição: = @ID_ITEM_TREINO + ID_TREINO + NM_EXERCICIO + QT_SERIES + QT_REPETICOES + (DS_CARGA)

Atributo Tipo Obrigatório Observação
ID_ITEM_TREINO int Sim (PK) Identificador do exercício na ficha
ID_TREINO int Sim (FK) Referencia TREINO
NM_EXERCICIO varchar(100) Sim Nome do exercício
QT_SERIES int Sim Número de séries
QT_REPETICOES int Sim Repetições por série
DS_CARGA varchar(30) Não Carga do exercício

UNIDADE

Filial da academia.

Composição: = @ID_UNIDADE + NM_UNIDADE + DS_ENDERECO

Atributo Tipo Obrigatório Observação
ID_UNIDADE int Sim (PK) Identificador da unidade
NM_UNIDADE varchar(100) Sim Nome da unidade
DS_ENDERECO varchar(255) Sim Endereço completo da unidade

CHAMADO_MANUTENCAO

Pedidos de reparo de equipamentos, abertos pelos funcionários.

Composição: = @ID_CHAMADO + ID_FUNCIONARIO_ABERTURA + DT_ABERTURA + DS_PROBLEMA + TP_STATUS

Atributo Tipo Obrigatório Observação
ID_CHAMADO int Sim (PK) Identificador do chamado
ID_FUNCIONARIO_ABERTURA int Sim (FK) Referencia FUNCIONARIO (quem abriu o pedido)
DT_ABERTURA datetime Sim Data e hora em que o chamado foi aberto
DS_PROBLEMA text Sim Descrição do defeito
TP_STATUS varchar(20) Sim Situação do chamado

ESTOQUE_MATERIAL

Materiais e itens mantidos em estoque em cada unidade da academia.

Composição: = @ID_MATERIAL + ID_UNIDADE + NM_MATERIAL + TP_MATERIAL + QT_ESTOQUE

Atributo Tipo Obrigatório Observação
ID_MATERIAL int Sim (PK) Identificador do material em estoque
ID_UNIDADE int Sim (FK) Referencia UNIDADE, indicando onde o material está armazenado
NM_MATERIAL varchar(100) Sim Nome ou identificação do material
TP_MATERIAL varchar(50) Sim Categoria ou tipo do material
QT_ESTOQUE int Sim Quantidade disponível em estoque
