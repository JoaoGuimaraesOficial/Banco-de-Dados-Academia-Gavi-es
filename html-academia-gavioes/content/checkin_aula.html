CHECKIN_AULA

4 atributos

Reserva de vaga de um aluno em uma aula coletiva (relação N:N entre ALUNO e AULA_COLETIVA).

Pertence a uma AULA_COLETIVA e a um ALUNO (N:1 para cada um).

Atributo Descrição Regra de negócio associada
ID_CHECKIN INT UNSIGNEDPKAI

Identificador único do check-in.

 Cada reserva de vaga é registrada de forma única.
ID_AULA INT UNSIGNEDFK → AULA_COLETIVANNUK

Aula reservada.

 Todo check-in refere-se a uma aula existente; a combinação (ID_AULA, ID_ALUNO) é única.
ID_ALUNO INT UNSIGNEDFK → ALUNONNUK

Aluno que realizou o check-in.

 Somente alunos com matrícula ativa fazem check-in, e cada aluno ocupa no máximo uma vaga por aula.
DT_REALIZACAO DATETIME DEFAULT CURRENT_TIMESTAMPNN

Momento em que o check-in foi feito.

 Define a ordem de ocupação das vagas e permite auditar as reservas.
