ALUNO

8 atributos

Pessoa cadastrada que utiliza os serviços da academia: treina, contrata planos e reserva aulas coletivas.

Relaciona-se com MATRICULA, TREINO e CHECKIN_AULA (1:N em todos).

Atributo Descrição Regra de negócio associada
ID_ALUNO INT UNSIGNEDPKAI

Identificador único do aluno, gerado automaticamente.

 Cada aluno possui um único código no sistema, que nunca se repete nem é reaproveitado.
NM_ALUNO VARCHAR(100)NN

Nome completo do aluno.

 O cadastro exige nome completo para identificação na recepção e no contrato.
ID_CPF CHAR(11)NNUK

CPF somente com dígitos, sem pontos ou traço.

 Um CPF só pode ter um cadastro de aluno; os dígitos verificadores devem ser validados antes da gravação.
NM_EMAIL VARCHAR(120)NNUK

E-mail principal de contato.

 Usado para avisos, cobranças e recuperação de acesso; não pode se repetir entre alunos.
DT_NASCIMENTO DATENN

Data de nascimento do aluno.

 Permite validar a idade mínima para matrícula e adequar o treino à faixa etária.
DS_FOTO_PERFIL VARCHAR(255)NL

Caminho ou URL da foto de perfil.

 A foto é exibida na recepção para conferência visual da identidade; é opcional.
DS_BIOMETRIA_FACIAL BLOBNL

Modelo (template) da biometria facial, não a imagem original.

 Usada no acesso por reconhecimento facial; só é armazenada com consentimento expresso do aluno (LGPD, dado pessoal sensível).
IN_ATIVO TINYINT(1) DEFAULT 1NN

Indicador de cadastro ativo (1 = ativo, 0 = inativo).

 Aluno inativo não acessa a academia; o cadastro é inativado, nunca excluído, para preservar o histórico.
